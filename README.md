# Turtlebot_Visual_Servoing
This repository contains various packages to implement visual servoing on Turtle Bot

## Simulation Setup
- Download the folder `turtlebot3_vs` it is a ros-2 package containing required files for visual servoing.
- Compile the package using `colcon build`
- Use following command to run the simualtion
  - `ros2 launch turtlebot3_vs visual_servoing.launch.py`
